# Frazeoteka 2

Файлы для публикации на GitHub Pages.

## Структура
- `index.html` — сайт
- `data/frazeoteka.json` — база словаря
- `README.md` — эта инструкция

## Как добавлять статьи
1. В ChatGPT получить словарную статью.
2. Скопировать JSON-блок под статьёй.
3. В Frazeoteka 2 нажать **Добавить**.
4. Вставить JSON.
5. Нажать **Добавить в словарь**.
6. При совпадении `headword_latin` существующая статья обновляется.

## GitHub Pages
Загрузите файлы в репозиторий, сохранив папку `data`.
Затем: Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
