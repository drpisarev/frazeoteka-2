GitHub как облачная база

Сайт читает и обновляет JSON-файл в вашем репозитории через GitHub API.
Для записи нужен доступ только к выбранному репозиторию и Repository permissions → Contents: Read and write. Не помещайте токен в исходный код.
Безопасность. Для статического сайта без собственного сервера GitHub OAuth нельзя реализовать безопасно без дополнительного backend. Поэтому токен вводится только на вашем устройстве. Используйте fine-grained token, ограниченный одним репозиторием; если не включать «Сохранять токен», он живёт только до закрытия вкладки.
